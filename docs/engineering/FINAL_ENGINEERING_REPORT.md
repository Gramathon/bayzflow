# Final SVI engineering report

Bayzflow introduces no additional error relative to equivalent direct Pyro in the tested uninterrupted Gaussian comparisons. Original installed source, original checkout and modified source all give full-rank covariance relative errors **.625819/.520021/.516623** at 2000 updates for seeds 11/23/37; corresponding mean errors are .03750/.03803/.03745. These engineering results reproduce the E07-style inadequacy without changing E07's NOT_SUPPORTED verdict.

The poor default recovery is associated with finite-budget stochastic optimization of an ill-conditioned correlated model and, for diagonal guides, missing covariance flexibility. Full-rank leading orientation is largely recovered while its broad variance is underestimated. Longer training and learning rate affect results. Whitening reduces covariance errors to .133–.232 but worsens mean recovery; larger initial scale worsens covariance recovery and float64 alone does not resolve it. Initialization, feature coordinates, prior and precision controls are reported with full metrics in POSTERIOR_FIDELITY_INVESTIGATION.md and validation/svi/tables.md. A unique universal root cause is not established. Incorrect summed Gaussian likelihood, an unintended deterministic backbone and a Bayzflow-specific single-fit objective discrepancy are excluded within these controls.

Confirmed defects: deep-copy isolation loses optimizer/global parameter identities at public call boundaries; empirical covariance extraction truncates float64 precision and scalarizes one-dimensional covariance. Corrections preserve references under the lock and preserve tensor-valued covariance precision/shape. These are genuine lifecycle/extraction fixes, not an invented explanation of uninterrupted E07 failure.

API additions: explicit freeze/joint deterministic policy (joint remains default); fit(continue_optimizer=True) for in-process Adam continuation; reset_optimizer(); setup_svi(restart_posterior=True); bounded structured diagnostics with covariance representation and coordinate metadata. Legacy fit boundaries still intentionally reset Adam by default. Cumulative history now retains earlier calls. Safe checkpoints preserve guide/model recovery and training-policy provenance; optimizer/RNG continuation across processes is unsupported and rejected explicitly. Trusted guide registration, checksum/tensor-only loading, sample limits and MCP restrictions remain intact.

Frozen-backbone, joint point-estimation and all-selected-supported-layers examples execute in bayzflow/examples/svi_training_controls.py. All-selected does not imply unsupported components are Bayesian. Covariance output distinguishes packed unconstrained moments from sampled native parameters; nonlinear support transforms require native draws.

Verification: focused suite **31 passed, 1 skipped**. Broad tracked suite **80 passed, 1 skipped, 1 failed**, with the frozen Phase5 direction-hash failure reproduced on untouched source. Untracked research tests also have pre-existing collection conflicts. Test logs and benchmark checksums are retained under validation/svi. No historical artifacts were repaired to force a pass. No production release readiness claim is warranted.

The implementation and proposed EXPCON_E09_VALIDATION_PLAN.md are ready for independent review and preparation of a frozen E09 contract. E09 has not been executed or passed. Production release remains blocked on full environment-compatible regression validation, independent posterior-fidelity validation and compatibility testing. No push, release or package-version change was made. Existing user modifications are preserved on engineering/svi-posterior-fidelity.

Changed implementation: bayzflow/core/engine.py and new bayzflow/core/svi_diagnostics.py. Added focused tests, independent validation utilities/results, executable examples and engineering documentation; README links the new controls and evidence. There are no unrelated package changes. The baseline audit, investigation, training regimes, engineering changes, validation, E09 plan and this report are the seven requested deliverables.
